# DOVELAMB Theme

A custom **Oh My Posh** theme designed as part of the **DOVELAMB Development Ecosystem**.

🌐 **Language**

- 🇺🇸 English
- 🇪🇸 [Español](docs/README.es.md)



## Purpose

The goal of this project is to provide a consistent, clean, and productive terminal experience across every DOVELAMB workstation, including:

- Windows Workstation
- Mobile Workstation
- Ubuntu Server
- VPS
- Future NAS

The theme is focused on displaying only meaningful information for software development, DevOps, automation, and cloud engineering.

---

## Planned Features

- DOVELAMB visual identity
- Workstation name
- Current user
- Current working directory
- Git repository status
- Current branch
- Java version
- Maven / Gradle
- Docker
- Node.js
- Kubernetes
- Cloud providers
- WSL / Linux

Additional integrations will be implemented as the DOVELAMB ecosystem evolves.

## Status

**Current Version:** v0.1.0

---

## Philosophy

DOVELAMB Theme is not intended to be just another terminal theme.

Its purpose is to provide meaningful contextual information while keeping the terminal clean, readable, and consistent across multiple workstations and operating systems.
