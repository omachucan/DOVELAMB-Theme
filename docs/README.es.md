# DOVELAMB Theme

🌐 **Idioma**

- 🇪🇸 Español
- 🇺🇸 [English](../README.md)

---

Tema personalizado para **Oh My Posh**, diseñado como parte del **ecosistema de desarrollo DOVELAMB**.

## Propósito

El objetivo de este proyecto es proporcionar una experiencia de terminal consistente, limpia y productiva en los diferentes equipos del ecosistema DOVELAMB, incluyendo:

- Workstation Windows
- Workstation móvil
- Servidor Ubuntu
- VPS
- Futuro NAS

El tema está orientado a mostrar únicamente información relevante para desarrollo de software, DevOps, automatización y cloud.

---

## Características previstas

- Identidad visual DOVELAMB
- Nombre de la estación de trabajo

## Estado

**Versión actual:** v0.1.0

---

## Filosofía

DOVELAMB Theme no pretende ser únicamente otro tema visual para la terminal.

Su propósito es proporcionar información contextual útil manteniendo una terminal limpia, legible y consistente entre diferentes estaciones de trabajo y sistemas operativos.
